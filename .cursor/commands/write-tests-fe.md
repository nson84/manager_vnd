Write tests for a **Frontend** feature in `FE/`.

Follow `FE/.cursor/commands/write-tests.md`:

1. Read feature source under `FE/src/features/`
2. Service tests: `{feature}Service.test.ts`
3. Component tests: `{Feature}Page.test.tsx`
4. Run: `cd FE && npm test`

Note: install Vitest + Testing Library first if not yet set up (see FE/docs/PROJECT-STATUS.md).
